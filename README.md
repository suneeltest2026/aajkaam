# Momentum — Priority Matrix

A single-page personal to-do app: four life areas, groups inside each one, and the four
Eisenhower priority boxes. Published from this branch with GitHub Pages.

* **Live app:** https://suneeltest2026.github.io/aajkaam/
* Everything is stored in the visitor's own browser (`localStorage`). No account, no server,
  no analytics, and no network requests once loaded — each person's list is private to their
  own device and invisible to everyone else.
* Works offline after the first visit, and can be installed to a phone's home screen.

The source of truth for the app is `momentum-todo.html` on the development branch; this branch
carries the built site (`index.html` plus the icons, manifest and service worker).
